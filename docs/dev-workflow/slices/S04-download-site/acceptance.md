# Acceptance — S04 下载站落地页

> 本刀验收以本文件为准；项目全局事实见 `docs/dev-workflow/context/`。

## 竖切目标

访客打开落地页即可分区下载客户端（四端）与 Linux 服务端安装包，并看到简明「下一步：安装 → 扫码/复制 → 客户端添加」指引；无节点列表、无强制登录。

## 范围内

- 落地页信息架构与实现
- 客户端 / 服务端下载入口与校验和展示（按规格）
- 去中心化说明与责任提示文案
- 与发布产物版本号对齐

## 范围外（本刀不做）

- 中心化节点发现、用户账号后台
- VPN 隧道功能本身

## 验收标准

| ID | 场景 | 前置 | 步骤 | 期望 | 优先级 |
|----|------|------|------|------|--------|
| AC-01 | 分区下载 | 落地页/store 已部署 | 打开下载站 | 清晰区分客户端与服务端下载区 | must |
| AC-02 | 客户端齐套入口 | 发布物已上传 | 检查下载链接 | Win/macOS/Android/iOS 均有入口（或明确「即将提供」仅当用户改 scope——当前为 must 齐套） | must |
| AC-03 | 服务端入口 | 同上 | 下载 Linux 包 | 可下载且附校验说明 | must |
| AC-04 | 无账号墙 | 访客未登录 | 下载 | 不要求注册/登录 | must |
| AC-05 | 无节点列表 | 浏览全站 | 检查导航与内容 | 不出现官方节点列表或一键连官方 | must |
| AC-06 | 傻瓜指引 | 新用户 | 阅读首页步骤 | ≤3 步说清安装→拿连接信息→客户端添加 | must |
