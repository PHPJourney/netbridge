网桥 VPN 是什么

网桥 VPN（NetBridge）是去中心化的自建 VPN：节点跑在您自己的服务器上，用 WireGuard 隧道把手机/电脑接到该节点。

  • 没有官方公共节点——本站不提供「一键连公共服务器」。
  • 没有账号体系——不注册、不登录；连接信息由您在服务器上生成并导入客户端。
  • 下载页只提供客户端与服务端安装入口；密钥与配置始终由您掌控。

三步流程（必读）

  1. 装服务端：在本页 部署服务端 选 Debian / Ubuntu / CentOS / RHEL，按一键命令安装。
  2. 拿连接信息：服务器上执行 sudo nbvpn show ，得到 URI、终端二维码或配置文件（等同密钥，勿公开发布）。
  3. 客户端添加并连接：在手机/电脑安装 客户端 ，用 URI / 扫码 / 文件导入后连接。

页顶「使用步骤」是同一流程的摘要；本区有更细的安装与排错说明。

安装服务端

当前正式支持的服务端系统：

  • Debian / Ubuntu（deb 系一键脚本；安装前评估环境，缺模块时尝试 headers/dkms）
  • CentOS / RHEL（含 Rocky / Alma；脚本评估内核/换 vault 源/提示 reboot；Stream 8 旧内核需注意）
  • Windows Server（Win10+/2016+ 用 Setup.exe；Server 2012 主推 Setup-win2012，勿用现代 Setup）

到 部署服务端 ：Linux 复制一键命令以 root / sudo 执行（curl|bash 会自动拉取配套脚本与 Releases 二进制）；Windows（2016+/Win10+）下载 Setup.exe 并以管理员运行；Server 2012 优先下载 Setup-win2012 双击安装（高级区另有 win2012 exe + install.ps1）。安装完成后会配置首个客户端 peer，并尽量启用服务。

Windows 服务端 MVP

在 部署服务端 的 Windows 卡片：Win10 / Server 2016+ 用 Setup.exe；Server 2012 / 2012 R2 主推 Setup-win2012 双击安装（含 WG 0.5.3 + Win32 GUI）。高级裸装：下载 nbvpn-windows-amd64-win2012.exe + install.ps1，管理员执行 install.ps1 -SkipWireGuard。详见 WINDOWS.md。

nbvpn 常用命令

安装完成后，在服务器终端执行（多数环境需 sudo）：

sudo nbvpn install

首次安装 / 修复配置，生成节点与首个客户端配置并尽量启用服务。

sudo nbvpn show

显示连接信息（默认 URI + 二维码 + 文件）。也可用 nbvpn show --uri / --qr / --file。

sudo nbvpn status

查看服务 / 隧道是否在运行。

sudo nbvpn start

启动 WireGuard 服务。

sudo nbvpn stop

停止服务。

sudo nbvpn peer add

为另一台设备再加一个客户端；可带名字，例如 sudo nbvpn peer add phone。添加后会再次展示该 peer 的 URI / 二维码 / 文件。

若公网 IP 检测失败，客户端连不上时请设置入口： sudo nbvpn config set endpoint <公网IP或域名> （可选端口，默认见下节）。

客户端如何导入

在电脑或手机安装网桥 VPN 客户端后，任选一种方式添加服务器：

  • URI：在服务器执行 sudo nbvpn show --uri ，把整段 URI 粘贴到客户端「添加服务器」。
  • 二维码：执行 sudo nbvpn show （或 --qr ），用手机客户端扫描终端里的二维码（桌面端若无相机，请改用 URI / 文件）。
  • 配置文件：用 nbvpn show --file 得到的 .nbvpn.json （或客户端支持的导入文件）拷到设备后选择「从文件导入」。
密钥警告

URI、二维码、配置文件都含客户端私钥，等同于密码。不要发到公开群、截图到社交网络，也不要提交到代码仓库。

端口、防火墙与 NAT

  • 默认监听 UDP 51820。请在主机防火墙与云厂商安全组同时放行该端口（只开 UDP，不要只开 TCP）。
  • 安装脚本会尽量开启 IP 转发（ip_forward） 与 MASQUERADE（NAT），让客户端流量经节点出口。若服务器已启用 ufw，还会自动 ufw allow 51820/udp 并放宽转发策略。
  • 连不上时优先检查：安全组是否放行 UDP 51820 → nbvpn status 是否在跑 → nbvpn show 里的 endpoint 是否为真实可达的公网地址。

云安全组 / ACL（控制台手动配置）

安装脚本无法修改云厂商面板。请在 VPS 控制台为本实例关联的安全组添加入站规则（白名单模式需显式允许）：

  • 规则写进安全组后，必须绑定到当前这台云主机；只加规则、不绑实例等于未生效。
  • 只开 TCP 22 / 80 / 443 不够，WireGuard 必须 UDP 51820（或你自定义的监听端口）。
  • 症状：tcpdump 能看到入站 UDP 但 wg show 无 latest handshake、无出站回包 → 常见为安全组未绑实例，或主机 ufw 未放行。

主机防火墙（安装脚本自动配置）

Linux 一键安装会在本机尝试：ufw allow 51820/udp（Debian/Ubuntu）或 firewall-cmd --add-port=51820/udp（RHEL 系且 firewalld 在跑）。跳过： NBVPN_SKIP_FIREWALL=1。验证：

sudo ufw status | grep 51820
sudo ufw allow 51820/udp comment 'nbvpn WireGuard'
